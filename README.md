个人竞赛获奖证书归档，覆盖电子设计、机器人、嵌入式、信息安全、物联网、智能制造等赛事。

| 类别 | 数量 | 说明 |
|------|------|------|
| [国家级](国家级/) | 18 | 国奖/全国总决赛奖项、国家级大创、国家励志奖学金 |
| [省级](省级/) | 18 | 省赛奖项、省级大创、赛区奖项 |
